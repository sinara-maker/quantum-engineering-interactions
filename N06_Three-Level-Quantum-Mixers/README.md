# N06 — Three-Level Quantum Mixers

Quantized Raman conversion, signed detunings, three-level topology, Stark-shifted resonance, and pair processes.

Canonical resource files use the stem `N06_Three-Level-Quantum-Mixers`. The `.ipynb`, `.html`, and `.pdf` files are source, browser-readable, and print-ready views of the same tutorial.

Article-scale figure identifiers: N06_MF1; N06_MF2. Numerical tables are in `data/`; vector and high-resolution figure exports are in `figures/`.

## Run on Windows, macOS, or Linux

From an Anaconda Prompt or terminal at the repository root:

```text
conda env create -f environment.yml
conda activate engineering-quantum-interactions
cd notebooks/N06_Three-Level-Quantum-Mixers
jupyter lab
```

Open the notebook, restart the kernel, and select **Run All Cells**. Parameters intended for adaptation are collected near the beginning. QuTiP is the canonical quantum-dynamics implementation.

Keywords: three-level atom; Raman transition; quantum frequency conversion; James-Jerke method; small rotations.
