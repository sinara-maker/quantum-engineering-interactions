# N00 — Companion Notebook Index

Reader map and machine-checkable entry point for the complete notebook collection.

Canonical resource files use the stem `N00_Companion-Notebook-Index`. The `.ipynb`,
`.html`, and `.pdf` files are source, browser-readable, and print-ready views of the
same index.

Run `N00_Companion-Notebook-Index.ipynb` from this directory after activating the
repository environment, or use `run_N00.bat` from Anaconda Prompt on Windows.

Keywords: effective Hamiltonian; quantum interaction engineering; reproducible quantum
dynamics; QuTiP.
