# N05 — Three-Photon Rabi Resonance

Shifted three-photon resonance, cubic coupling, virtual-state reconstruction, and predictive-time validation.

Canonical resource files use the stem `N05_Three-Photon-Rabi-Resonance`. The `.ipynb`, `.html`, and `.pdf` files are source, browser-readable, and print-ready views of the same tutorial.

Article-scale figure identifier: `N05_MF1`. Supplemental figure identifier: `N05_SF1`. Numerical tables are in `data/`; vector and high-resolution figure exports are in `figures/`.

## Run on Windows, macOS, or Linux

From an Anaconda Prompt or terminal at the repository root:

```text
conda env create -f environment.yml
conda activate engineering-quantum-interactions
cd notebooks/N05_Three-Photon-Rabi-Resonance
jupyter lab
```

Open the notebook, restart the kernel, and select **Run All Cells**. Parameters intended for adaptation are collected near the beginning. QuTiP is the canonical quantum-dynamics implementation.

Keywords: quantum Rabi model; three-photon resonance; multiphoton avoided crossing; higher-order effective Hamiltonian; virtual-state reconstruction; resonance calibration; QuTiP.
