# N03 — Floquet-Controlled Tunnelling

Bessel-renormalized hopping, coherent destruction of tunnelling, quasienergy gauge, micromotion, and Sambe-space checks.

Canonical resource files use the stem `N03_Floquet-Controlled-Tunnelling`. The `.ipynb`, `.html`, and `.pdf` files are source, browser-readable, and print-ready views of the same tutorial.

Article-scale figure identifiers: N03_MF1; N03_MF2. Numerical tables are in `data/`; vector and high-resolution figure exports are in `figures/`.

## Run on Windows, macOS, or Linux

From an Anaconda Prompt or terminal at the repository root:

```text
conda env create -f environment.yml
conda activate engineering-quantum-interactions
cd notebooks/N03_Floquet-Controlled-Tunnelling
jupyter lab
```

Open the notebook, restart the kernel, and select **Run All Cells**. Parameters intended for adaptation are collected near the beginning. QuTiP is the canonical quantum-dynamics implementation.

Keywords: Floquet engineering; coherent destruction of tunnelling; micromotion; Sambe space; effective Hamiltonian.
