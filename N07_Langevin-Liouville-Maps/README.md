# N07 — Langevin, Liouville-Space, and Dynamical Maps

Heisenberg--Langevin equations, Gaussian channels, input--output fields, Liouville-space maps, physicality, and memory.

Canonical resource files use the stem `N07_Langevin-Liouville-Maps`. The `.ipynb`, `.html`, and `.pdf` files are source, browser-readable, and print-ready views of the same tutorial.

Article-scale figure identifiers: N07_F11. Numerical tables are in `data/`; vector and high-resolution figure exports are in `figures/`.

## Run on Windows, macOS, or Linux

From an Anaconda Prompt or terminal at the repository root:

```text
conda env create -f environment.yml
conda activate engineering-quantum-interactions
cd notebooks/N07_Langevin-Liouville-Maps
jupyter lab
```

Open the notebook, restart the kernel, and select **Run All Cells**. Parameters intended for adaptation are collected near the beginning. QuTiP is the canonical quantum-dynamics implementation.

Keywords: Heisenberg-Langevin equations; Liouville space; Gaussian channel; input-output theory; non-Markovian dynamics.
