# N04 — Lossy Bosonic Mediator

Open-system adiabatic elimination, induced coherent and dissipative interactions, reconstruction, physicality, and memory.

Canonical resource files use the stem `N04_Lossy-Bosonic-Mediator`. The `.ipynb`, `.html`, and `.pdf` files are source, browser-readable, and print-ready views of the same tutorial.

Article-scale figure identifiers: N04_MF1; N04_MF2. Numerical tables are in `data/`; vector and high-resolution figure exports are in `figures/`.

## Run on Windows, macOS, or Linux

From an Anaconda Prompt or terminal at the repository root:

```text
conda env create -f environment.yml
conda activate engineering-quantum-interactions
cd notebooks/N04_Lossy-Bosonic-Mediator
jupyter lab
```

Open the notebook, restart the kernel, and select **Run All Cells**. Parameters intended for adaptation are collected near the beginning. QuTiP is the canonical quantum-dynamics implementation.

Keywords: adiabatic elimination; open quantum systems; lossy cavity; effective operators; Liouvillian.
